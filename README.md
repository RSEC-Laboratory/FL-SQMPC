# FL-SQMPC

Reference implementation for the paper:

> **FL-SQMPC: Secure Quantized Aggregation for Mitigating Gradient Inversion
> Attacks in Federated IoT Intrusion Detection**
> Imene Bessaa, Zakaria Abou El Houda, Lyes Khoukhi.

FL-SQMPC is a secure aggregation scheme that combines layer-wise mixed-precision
quantization with fixed-point encoding and additive secret sharing over a prime
field, so the server observes only a quantized cohort aggregate. This repository
provides the full federated-learning training pipeline, baseline implementations
(HE, DP-SGD, CIDIoT, FedAvg), and the gradient-inversion (TabLeak / DLG / iDLG)
evaluation used in the paper.

## Installation

```bash
# Python 3.10+ recommended
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The Paillier-HE baseline additionally requires
[Pyfhel](https://github.com/ibarrond/Pyfhel) (`pip install Pyfhel`). DP-SGD with
RDP accounting requires [opacus](https://opacus.ai/) (`pip install opacus`).

## Datasets

The three IDS datasets used in the paper are publicly available. We do **not**
redistribute them — download them from the official sources:

| Dataset | Source |
|---|---|
| Bot-IoT | https://research.unsw.edu.au/projects/bot-iot-dataset |
| ToN-IoT | https://research.unsw.edu.au/projects/toniot-datasets |
| CIC-IoT-2023 | https://www.unb.ca/cic/datasets/iotdataset-2023.html |

After downloading, place the raw CSVs as:

```
Bot_IoT_raw/Bot-IoT 1.csv
ToN_IoT_raw/ToN_IoT_extracted 1.csv
ciciot2023_raw/CicIoT_extracted02.csv
```

Then run the preprocessing scripts:

```bash
.venv/bin/python scripts/preprocess_ciciot2023_tensor.py
.venv/bin/python scripts/preprocess_ton_iot.py
.venv/bin/python scripts/preprocess_ton_iot_tensor.py
.venv/bin/python scripts/rescale_bot_iot_minmax.py
```

The fitted scalers (`scaler.pkl`), one-hot encoders (`ohe.pkl`), and dataset
metadata (`meta.json`) are committed under each `*_processed*/` directory, so the
preprocessing pipeline is reproducible bit-for-bit from the raw inputs.

## Running experiments

### Single FL run

```bash
.venv/bin/python scripts/run_fl_sqmpc_accuracy.py \
    --dataset ciciot2023_processed/CicIoT_extracted02.csv \
    --task multiclass --partition iid \
    --mode sqmpc --clients 5 --rounds 30 --batch-size 100 \
    --learning-rate 1e-3 --optimizer adam \
    --hidden-sizes 128,64 --seed 42 \
    --output-dir output/results/my_run
```

`--mode` selects the aggregation backend:

- `sqmpc` — FL-SQMPC mixed-precision quantization + additive secret sharing
- `he` — Paillier-style homomorphic-encryption baseline
- `dpsgd` — DP-SGD with RDP accountant (uses `--dp-epsilon`, `--dp-clip-norm`)
- `plain` — vanilla FedAvg

### Six-method comparison (paper Figure 4 / Table 3)

```bash
.venv/bin/python scripts/run_method_comparison.py \
    --datasets ciciot2023,ton_iot_extracted,bot_iot \
    --seeds 42,43,44 \
    --rounds 30 --clients 5 --batch-size 100 \
    --output-dir output/results/method_comparison
```

This runs `{SQMPC@lr2e-4, SQMPC@lr1e-3, HE, DP-SGD ε=8, DP-SGD ε=50, CIDIoT}` × 3
seeds × 3 datasets × {IID, Dirichlet α=0.3}.

### Dirichlet non-IID sweep

```bash
.venv/bin/python scripts/run_sqmpc_dirichlet_experiments.py \
    --output-dir output/results/sqmpc_dirichlet
```

### Quantization bits ablation

```bash
.venv/bin/python scripts/run_sqmpc_bits_ablation.py \
    --output-dir output/results/bits_ablation
```

### Gradient-inversion privacy evaluation (TabLeak)

```bash
.venv/bin/python scripts/run_tableak_evaluation.py \
    --method sqmpc --dataset ciciot2023 --batch-size 1 \
    --output-dir output/results/tableak
```

The `scripts/attacks/` package implements the three inversion attacks used in
the paper: **TabLeak**, which is a softmax-relaxed tabular reconstruction (with
both single-step and FedAvg variants).

### Generating figures and tables

After the runs finish, the `generate_*.py` scripts read the result JSON files
and produce paper-ready PDF/SVG figures and Markdown/CSV tables. For example:

```bash
.venv/bin/python scripts/generate_method_comparison_figures.py \
    --results-dir output/results/method_comparison \
    --output-dir output/figures/method_comparison
```

## Reproducing the paper

End-to-end reproduction:

```bash
# 1. Preprocess (one-off)
.venv/bin/python scripts/preprocess_ciciot2023_tensor.py
.venv/bin/python scripts/preprocess_ton_iot.py
.venv/bin/python scripts/preprocess_ton_iot_tensor.py
.venv/bin/python scripts/rescale_bot_iot_minmax.py

# 2. Main accuracy comparison
.venv/bin/python scripts/run_method_comparison.py --output-dir output/results/main

# 3. Ablations
.venv/bin/python scripts/run_sqmpc_dirichlet_experiments.py --output-dir output/results/dirichlet
.venv/bin/python scripts/run_sqmpc_bits_ablation.py        --output-dir output/results/bits

# 4. Gradient-inversion privacy evaluation
bash scripts/run_tableak_ciciot_ton_b1_parallel.sh

# 5. Figures and tables
.venv/bin/python scripts/generate_method_comparison_figures.py --results-dir output/results/main --output-dir output/figures/main
.venv/bin/python scripts/generate_sqmpc_dirichlet_figures.py   --results-dir output/results/dirichlet
.venv/bin/python scripts/generate_sqmpc_bits_ablation_figure.py
.venv/bin/python scripts/generate_recon_table.py
.venv/bin/python scripts/generate_tableak_attack_report.py
```

All runners accept `--seed`, write deterministic dataset/partition fingerprints
into their result JSON, and use CPU by default (set `--device mps` or `--device
cuda` if available).
